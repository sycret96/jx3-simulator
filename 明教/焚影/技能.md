## 一、资源与核心机制

明教围绕日 / 月双资源运转，先把机制层写清楚，技能怎么转就明白了。

- **资源类型**：日灵 / 月魂，上限各 **100**
- **获取**：赤日轮 +20 日灵/段、烈日斩 +40 日灵；幽月轮 +20 月魂/段、银月斩 +40 月魂
- **锁死规则（核心）**：一种能量满了之后，**无法继续获得另一种**，直到把满能量状态消耗掉；攒满一种的瞬间不清空另一种
- **消耗**：净世破魔击、生死劫 需消耗「满日」或「满月」，一次性清空对应满资源
- **日珥 / 月芒（齐光流）**：
  - 烈日斩 / 银月斩 命中**非侠士目标** → 自身获得可叠加的「日珥」/「月芒」
  - 同时拥有两者时，全部消耗并转化为**等层数**「光明相」（层数按 `min(珥, 芒)` 配对，余数保留 —— 待确认）
  - 「光明相」期间无法再获得珥 / 芒
  - 珥 / 芒 **≥2 层**时，消耗对应满灵可重置「驱夜断愁」调息并允许无视方位施展
- **光明相**：使 10s 内下次消耗满灵的招式**立即返还满灵**且必定会心，触发时额外造成 20–44 (+4174) 阳性内功伤害（非侠士 ×3.65）

## 三、技能详细档案

### 赤日轮

- **类型**：主动输出 / 日灵生成（三段连击）
- **CD / GCD**：无调息 · 瞬发，每段占 1 个 GCD
- **距离 / 目标数**：4 尺（+2 尺）· 一段单体 / 二段至多 3 / 三段至多 6
- **资源**：+20 日灵/段
- **伤害**（阳性内功 + 100% 武器伤害）
  - 一段 14 (+2129) · 二段 15 (+2129) · 三段 16 (+2655)
- **联动**：受「烈日」debuff 影响，伤害 **+50%**
- **备注**：三段需连续施放，被其他技能打断则回到一段

### 幽月轮

- **类型**：主动输出 / 月魂生成（三段连击，与赤日轮对位）
- **CD / GCD**：无调息 · 瞬发
- **资源**：+20 月魂/段
- **伤害**（阴性内功 + 100% 武器伤害）
  - 一段 7 (+1636) · 二段 7 (+1636，**会心 +5%**) · 三段 7 (+1870，**会心 +10%**)
- **备注**：后两段自带会心加成

### 烈日斩

- **类型**：主动输出 / 施加 debuff（日线点燃技 + 日珥来源）
- **CD**：6s，秘籍「调息 +9s 换 3 层充能」→ 15s / 3 层
- **资源**：+40 日灵
- **伤害**：15.5 (+2387) 阳性内功 + 100% 武器伤害
- **debuff**：命中挂「烈日」18s → 目标受到自身**赤日轮**伤害提高 **50%**
- **齐光流**：命中非侠士 → 自身 +1「日珥」
- **备注**：秘籍核心是「调息 +9s 换 3 层」的权衡

### 银月斩

- **类型**：主动输出 / 施加 debuff（月魂线，与烈日斩对位）
- **CD**：同烈日斩 · 3 层充能
- **资源**：+40 月魂
- **伤害**：9.5 (+1198) 阴性内功 + 100% 武器伤害
- **debuff**：命中挂「银月」18s DOT，**每 2s 一跳**（每跳伤害 `（？）` 待实测，排轴器里默认 0）
- **齐光流**：命中非侠士 → 自身 +1「月芒」

### 净世破魔击

- **类型**：主力输出 / 日月双形态
- **CD**：无调息 · 瞬发
- **资源**：消耗满日或满月（一次清空）；秘籍后消耗满月额外 **+20 月魂**
- **伤害**
  - **满日**：9.5 (+3372) 阳性内功 + **200%** 武器伤害，面向 15 尺扇形至多 5 目标，**其余目标半伤**
  - **满月**：突进 + 眩晕 2s，连续攻击 3 次，每次 7 (+1123) 阴性内功 + 100% 武器伤害
- **秘籍**：伤害 +4% / +5%，会心 +5%
- **联动**：命中**自身「斩不利」效果**的目标 → 额外 10–12 (+1114) 伤害，非侠士再 **+75%**
  - 该联动来自第四重【净体不畏】；**本点法选【靡业报劫】而非【净体不畏】，故排轴器默认关闭（`zhanbuli=false`）**
  - 公告已明确对应关系：斩击吃「异色」+50%、净世吃「同色」附加，非侠士 +75%

### 生死劫

- **类型**：资源释放技 / 控制
- **CD**：15s · 2 层充能（秘籍）
- **资源**：消耗满日或满月
- **伤害**：7.5 (+280)，极低（满日阳性 / 满月**阴性**）
- **附加**：满日 → 眩晕 4s；满月 → 目标受到治疗效果降低 50%，12s
- **秘籍（核心，对非侠士）**：
  1. 获得对应「日珥」或「月芒」
  2. **返还异色满灵**（消耗满日则返还满月）
  3. 随后**全部月芒转为日珥、日珥转为月芒**（颜色互换，用于主动调整层数）
  - ⚠️ 三步的**执行顺序为推测**，实测后确认

### 光明相

- **类型**：爆发核心 / 循环发动机
- **CD**：1 分 35s，秘籍 -30s → 65s
- **核心**：10s 内下次消耗满灵的招式，命中后**立即获得满灵**（资源返还）且**必定会心**
- **触发伤害**：20–44 (+4174) 阳性内功，非侠士 ×**3.65**
  ⚠️ 这段额外伤害来自第二重奇穴【崇光斩恶】，不是光明相自带 —— 见第五节
- **获取途径**：① 主动施放；② 日珥 + 月芒 合成
- ✅ 「生效时不再使招式必会心」已由官方公告确认为【日月同辉】的固有代价，不是情报矛盾。
  排轴器默认：**主动施放的必会心，自动合成的不必会心**，配置项 `gmAutoCrit` 可切换

### 驱夜断愁

- **类型**：隐身姿态爆发 / 资源获取
- **CD**：25s · 瞬发
- **释放条件**（公告调整后）：处于「渐隐」或「伪装」状态，**或处于目标背后**时可施展
- **资源**：+60 日灵、月魂（公告原文；装【明焰续夜】后降为 40 点）
- **资源方向**（明焰续夜）：跟随当前「日珥 / 月芒」——有月芒给月魂、有日珥给日灵；两者都没有时回落补较低的一边（因「日月同辉」下珥+芒会立即合成光明相，施放时珥芒不可能同时存在）
- **伤害**：9 (+3398) 阴性内功 + **200%** 武器伤害；**背后施展 +30%**
- **联动**：进入「渐隐」/「伪装」会重置本次调息
  （珥 / 芒 ≥2 层消耗满灵也重置 —— 但该效果来自混选奇穴【明焰续夜】，非基础自带）

### 暗尘弥散

- **类型**：隐身 / 脱战（解控）
- **CD**：40s 充能
- **效果（战斗中）**：清除移动限制，进入「伪装」5s，重置驱夜断愁
- **效果（非战斗）**：返还调息，伪装 60s
- **备注**：非输出循环常驻技能，用于起手与机制应对
- **注意（已修正）**：**瞬发、不占公共调息（GCD）**，可在任意 GCD 之间插入而不拖延后续技能时序；排轴器已按此实现，时间轴中画成虚线小标记（区别于占 GCD 的实块）

## 五、官方公告已澄清的项

来源同上（2026-09-08「苍生铸世」首轮武学调整）。这些此前被当成「技能自带 / 秘籍」，实际**来自奇穴**：

- **斩不利的对应关系**（第四重【净体不畏】）：
  「烈日斩」「银月斩」吃**异色**斩不利 → 伤害 +50%；
  「净世破魔击」吃**同色**斩不利 → 附加对应属性伤害，非侠士 +75%。
  → 不再是待实测项；但**本点法选【靡业报劫】而非【净体不畏】，排轴器 `zhanbuli` 默认关闭**。
- **光明相「不再必会心」**（第一重【日月同辉】原文）：不是情报矛盾，而是这颗奇穴的固有代价。
  → `gmAutoCrit` 默认关是对的。
- **生死劫的「秘籍」效果**（第五重【双曜转辉】）：得珥/芒 + 返还异色满灵 + 颜色互换，
  以及「2 层充能 / 15 秒」都是这颗奇穴给的。公告顺序为「获得珥芒 → 返还异色满灵 → 随后颜色互换」，
  与排轴器实现一致；「获得」与「返还」的先后仍含糊，但影响不大。
- **「烈日斩 / 银月斩 +9s 换 3 层」**：来自【日月同辉】。当前固定点法必点，引擎已写死 15s / 3 层（`cdDual` / `maxDual`）。
- **光明相额外伤害 365%**（第二重【崇光斩恶】）：不是光明相自带，需这颗奇穴才有。
- **驱夜断愁**：基础招式给 **60 点**（公告原文），装【明焰续夜】后变 **40 点**，
  且「珥/芒 ≥2 层重置调息 + 无视方位」**只在该奇穴下成立**。
- **无双 +20% / 无视 30% 内功防御 / 距离 +2 尺**：来自混选【日月耀临】，对应配置项 `arPen`。

逐条对应关系与改造清单见 [`奇穴.md`](./奇穴.md) 第八节。
