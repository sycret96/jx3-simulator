## 〇、招式调整（非奇穴，但改了循环）

- **驱夜断愁**
  - 调整后：处于 `[渐隐]` 或 `[伪装]` 状态下，**或处于目标背后时可施展**
    （原为「离开上述状态后 3 秒内方可施展」）
  - 获得 60 点日灵、月魂，对目标造成阴性内功伤害和 200% 武器伤害
  - **进入 `[渐隐]` 或 `[伪装]` 会重置本招式调息时间**
  - 在目标背后施展时伤害提高 30%
  - **调息时间调整为 25 秒**

| 被动招式 | **寂灭劫灰** | 「净世破魔击」命中侠士目标附带 `[寂灭]` 效果，持续 4 秒，至多叠加 3 层，层数溢出时转化为 2 秒持续时间。消耗满月施展「生死劫」会回收 40 尺内目标的「寂灭」效果并施加给当前目标，以此方式施加最大层数时本次「生死劫·月」造成的伤害提高 60%，「月劫」效果提升至 60%。`[寂灭]`：每层使受到效果来源「净世破魔击」「驱夜断愁」伤害提高 20%。 |

## 八、与排轴器的对照

⚠️ **重要**：整理这份表时发现，之前情报里被当成「技能自带 / 秘籍」的若干效果，实际来自奇穴。
排轴器目前把这些写成了常量或配置项，**没有区分是否点了该奇穴**。下面逐条标出来。

### 已实现（已按固定点法写死，非开关）

> 当前测试服固定点法 = 日月同辉 / 崇光斩恶 / 无明业火 / 靡业报劫 / 双曜转辉 / 日月齐光 / 明光恒照 / 日月耀临 / 明焰续夜。
> 引擎不再做奇穴开关，直接按这套点法实现；下表记录每个效果在引擎里的落点。

| 奇穴 | 引擎里的落点 |
| --- | --- |
| **日月同辉**（一重核心） | 珥/芒体系（`ermang`）、烈日银月 15s/3 层（`cdDual`/`maxDual`）、光明相不再必会心（`gmAutoCrit=false`） |
| **崇光斩恶**（二重） | 光明相额外伤害固定为非侠士 ×3.65 |
| **双曜转辉**（五重） | 生死劫 `cdSSJ=15`/`maxSSJ=2`、得珥芒+返异色满灵+颜色互换（`ssjSecret`，仅非侠士触发） |
| **明焰续夜**（混选） | 驱夜断愁 `+40`（非 60）、珥芒≥2 重置 CD 并无视方位（由 `ermang` 条件触发） |
| **净体不畏**（四重） | **未点**：本点法选【靡业报劫】，斩不利附加关闭（`zhanbuli=false`） |
| **五明乐见**（五重） | **未点**：光明相仍 95s、单次生效 |
