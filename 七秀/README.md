## 开工时的做法

1. 建 `七秀/冰心诀/`（或 `云裳心经/`）子目录
2. 从 `../明教/焚影/` 复制 `index.html` 与 `engine.test.js` 当模板
3. 改写 engine 里的 `SKILLS` 表与 `DEFAULT_CFG`
4. 新建 `技能.md`、`奇穴.md`
5. 回顶层 `index.html` 把这个心法从「未开始」改成可点链接

## 引擎需要为新门派预留什么

目前引擎是**单职业**实现（`SKILLS` 是一张扁平表，资源字段写在 `simulate` 里）。
加第二个门派前，建议先把这几处抽出来，避免各心法互相污染：

- **资源定义**：日灵 / 月魂是写死在 `simulate` 里的，新门派有自己的资源（如剑气、内力）时需要参数化
- **localStorage key**：现在是 `jx3shell:焚影`，每个心法必须不同，否则序列串味
- **时间轴行**：技能 / 资源 / buff 的行定义 `ROWS` 要能按心法配置
