## 引擎侧要注意

万花系多半涉及 **DOT 与持续治疗**（花间的玉石俱焚 / 离经的握针等），而现在的 DOT 实现比较粗糙——
只有「固定间隔跳数 + 提前刷新吞掉剩余跳」这一套，没有做：

- DOT 的**快照 / 动态刷新**区别
- 多个独立 DOT 实例的并存与分别结算
- 治疗量统计（当前统计口径只有伤害与 DPS）

加之前建议先把 DOT 模块单独抽出来重写一遍，否则会在两个心法里各踩一次坑。
