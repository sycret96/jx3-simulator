# JX3 in the Shell · 剑网三排轴器

给《剑网3》做循环规划的单文件排轴器。在时间轴上摆技能，引擎按该心法的机制实时算出伤害、资源、冷却，并指出循环里的卡点。

设计上参考了 FFXIV 的 [XIV in the Shell](https://xivintheshell.com/)（职业模拟器 + 时间轴规划），但它是独立实现，没有复用其代码。

## 目录结构

按 **门派 → 心法** 分层，每个心法自带排轴器与两份资料档：

```

├── 焚影/               焚影圣诀（输出）

七秀/                   冰心诀 / 云裳心经 · 待规划
万花/                   花间游 / 离经易道 · 待规划
```

## 使用

- **本地**：浏览器打开顶层 `index.html` 选心法，或直接打开 `明教/焚影/index.html`。无需安装，可离线。
- **在线**：仓库 Settings → Pages 把 source 设为 `main` 分支根目录后，访问 `https://sycret96.github.io/jx3-simulator/`。

界面左边点技能插入序列（选中某项后新技能插到它后面），中间是时间轴，下面是伤害统计和逐条施放记录。序列自动存在浏览器本地（每个心法独立），也可以导出/导入 JSON。

时间轴从上到下：技能块、日灵、月魂、日珥、月芒、光明相、伪装。灰色块 = 等 CD，红框 = 这一手套不进去。

## 明教·焚影 已实现的机制

细节见 [`明教/焚影/技能.md`](./明教/焚影/技能.md)，这里只列要点：

- **日灵 / 月魂**：上限 100，**一种满了之后另一种无法获得**，直到把满能量状态消耗掉。工具会标出被锁死和溢出的点数。
- **日珥 / 月芒 → 光明相**：烈日斩 +1 珥、银月斩 +1 芒（限非侠士）；两者并存时配对消耗合成等层数「光明相」，期间不再获得珥/芒。
- **光明相**：主动开启或由珥+芒合成，触发时该次耗灵招式立即返还满灵，因此可连发净世。
- **生死劫翻转**：消耗满灵对非侠士时返还异色满灵，并把珥芒颜色互换。
- **驱夜断愁联动**：进伪装 / 珥芒 ≥2 层消耗满灵都会重置它的调息。

## 开发

排轴引擎单独放在各心法 `index.html` 的第一个 `<script id="engine">` 里，不依赖 DOM，末尾 `module.exports`，可以被 node 直接提取测试：

```bash
cd 明教/焚影
node engine.test.js
```

测试用 `vm` 抽出 engine 块跑 45 条断言：资源锁死、净世/生死劫双形态、秘籍返还、珥芒合成、光明相主动与自动、驱夜断愁 CD 重置、充能等待、连击段、会心、AoE、DOT 跳数等。**改引擎后务必重跑。**

### 加一个新心法

1. 复制 `明教/焚影/` 整个目录到 `门派/心法/`
2. 改 engine 里的 `SKILLS` 表与 `DEFAULT_CFG`
3. **改 `STORE_KEY`**（现在是 `jx3shell:明教/焚影`），否则不同心法共用一份本地序列会串味
4. 改 `ROWS`（时间轴行定义）与 `engine.test.js` 的断言
5. 建 `技能.md`、`奇穴.md`
6. 回顶层 `index.html` 把它从「未开始」改成可点链接

已知待重构：资源字段（日灵/月魂）目前写死在 `simulate` 里，DOT 模块也比较粗糙。加第二个门派前建议先把这两处参数化，见 `七秀/README.md` 与 `万花/README.md`。
