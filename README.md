# JX3 in the Shell · 剑网三排轴器

给《剑网3》做循环规划的单文件排轴器。在时间轴上摆技能，引擎按职业机制实时算出伤害、资源、冷却，并指出循环里的卡点。

设计上参考了 FFXIV 的 [XIV in the Shell](https://xivintheshell.com/)（职业模拟器 + 时间轴规划），但它是独立实现，没有复用其代码。

**当前只做了明教（齐光流）一个职业**，其余职业待补。

## 使用

- **本地**：直接用浏览器打开 `index.html`，无需安装任何东西，可离线。
- **在线**：在仓库 Settings → Pages 里把 source 设为 `main` 分支根目录后，访问 `https://sycret96.github.io/jx3-simulator/`。

界面左边点技能插入序列（选中某项后新技能插到它后面），中间是时间轴，下面是伤害统计和逐条施放记录。序列自动存在浏览器本地，也可以导出/导入 JSON。

时间轴从上到下依次是：技能块、日灵、月魂、日珥、月芒、光明相、伪装。灰色块代表等 CD，红框代表这一手套不进去（比如资源没满就开了净世）。

## 已收录技能

| 技能 | 类型 | 关键机制 |
| --- | --- | --- |
| 赤日轮 | 日灵生成·三段 | +20 日灵/段；受「烈日」+50% |
| 幽月轮 | 月魂生成·三段 | +20 月魂/段；二三段自带会心 +5%/+10% |
| 烈日斩 | 充能 3 层 | +40 日灵；挂「烈日」18s；命中非侠士 +1 日珥 |
| 银月斩 | 充能 3 层 | +40 月魂；挂「银月」DOT 18s；命中非侠士 +1 月芒 |
| 净世破魔击 | 耗灵 | 满日 = 扇形 AoE（至多 5 目标，其余半伤）；满月 = 突进 3 连击 |
| 生死劫 | 耗灵·充能 2 层 | 伤害极低；秘籍 → 得珥/芒 + 返还异色满灵 + 珥芒颜色互换 |
| 光明相 | CD 95s | 10s 内下次耗灵招式必会心并立即返还满灵，附带高额额外伤害 |
| 驱夜断愁 | CD 25s | +60 资源；背后 +30%；进伪装重置 CD；珥/芒 ≥2 层可免方位 |
| 暗尘弥散 | 充能 40s | 进「伪装」5s，重置驱夜断愁 CD |

## 实现的机制

- **日灵 / 月魂**：上限 100，**一种满了之后另一种无法获得**，直到把满能量状态消耗掉；攒满瞬间不清空另一种。这是明教循环最容易踩的坑，工具会在时间轴上标出被锁死和溢出的点数。
- **日珥 / 月芒 → 光明相**：烈日斩 +1 珥、银月斩 +1 芒（限非侠士）；两者同时存在时配对消耗，合成等层数「光明相」；光明相期间不再获得珥/芒。
- **光明相**：主动开启（10s 窗口）或由珥+芒自动合成。触发时该次耗灵招式立即返还满灵，因此可以连发净世。自动合成的那一档按情报「生效时不再使招式必会心」处理，默认不必会心。
- **生死劫翻转**：消耗满灵对非侠士时返还异色满灵，并把全部月芒转为日珥、日珥转为月芒，可主动调整珥芒层数。
- **驱夜断愁联动**：进伪装 / 珥芒 ≥2 层消耗满灵都会重置它的调息。

## 规则待实测

下面几条情报里没给死，实现成了可在界面右侧勾选/填写的配置，实测后改一下即可：

- 「银月」DOT 每跳伤害（情报缺失，默认 0，填了才计入）
- 日珥与月芒层数不等时合成几层（目前按 `min(珥, 芒)` 配对，余数保留）
- 生死劫内部「得 buff → 返灵 → 颜色互换」的执行顺序
- 净世「斩不利」附加伤害的同色/异色对应关系（目前简化为：目标带烈日或银月任一即附加）
- 自动合成的「光明相」是否必会心（配置项 `gmAutoCrit`）

## 开发

排轴引擎单独放在 `index.html` 的第一个 `<script id="engine">` 里，不依赖 DOM，末尾 `module.exports`，可以直接被 node 提取出来测试。

```bash
node engine.test.js
```

测试用 `vm` 抽出 engine 块，跑 45 条断言：资源攒满与锁死、净世/生死劫双形态、秘籍返还、珥芒合成、光明相主动与自动、驱夜断愁 CD 重置、充能等待、连击段、会心、AoE、DOT 跳数、空序列等。**改引擎后请务必重跑。**

要加技能，只改 engine 里的 `SKILLS` 表；要加职业，照 `SKILLS` / `DEFAULT_CFG` / `simulate` 的结构再复制一份即可。
